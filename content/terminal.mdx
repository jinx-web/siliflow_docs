# Integrated Silicon Terminal

SiliFlow embeds a **multi-session shell terminal** directly in the bottom panel so build scripts, `make`, Git, and CLI EDA checks stay side by side with your RTL.

{/* SCREENSHOT_SLOT: docs-integrated-terminal.png — Bottom Integrated Terminal panel with multi-shell tabs and active toolchain PATH */}

---

## 1. Opening & Toggling

- Press <kbd>Ctrl+\`</kbd> (or <kbd>Ctrl+~</kbd> / <kbd>Ctrl+J</kbd>).
- Click the **Terminal** tab in the bottom panel or the Terminal icon in the bottom Status Bar.

---

## 2. Shell Auto-Detection & Multi-Tab Sessions

SiliFlow detects installed shells on your host via `get_available_shells`:

- **Windows**: PowerShell / PowerShell 7, Command Prompt (`cmd.exe`), and Git Bash (`bash.exe`) when present.
- **macOS / Linux**: Your default login shell (`zsh`, `bash`, `sh`).

Create multiple independent terminal sessions (**`+`**), split terminal views, switch shells cleanly, copy command output, and keep working directories automatically synced to your active project root.

---

## 3. Automatic EDA Toolchain `PATH` Injection

On Windows, MSYS2 and OSS CAD Suite binaries are often outside your global OS `PATH`. Whenever SiliFlow spawns an internal terminal or runner process, it scans managed tool paths (`%LOCALAPPDATA%\Siliflow\tools` / `~/.siliflow/tools`) and common toolchain directories (`C:\msys64\ucrt64\bin`, `C:\oss-cad-suite\bin`, etc.) so commands like `iverilog -V`, `verilator --version`, `yosys -V`, `slang --version`, and `sv2v` work immediately inside SiliFlow.
