# Waveform Viewer Guide

The SiliFlow Embedded Waveform Viewer is built directly into the core editor layout. It replaces clumsy external GTKWave popups with a hardware-accelerated WebGPU/Canvas renderer capable of streaming multi-gigabyte `.vcd` and `.fst` waveform traces smoothly at 60 FPS.

---

## Key Capabilities

- **Zero-Window Juggling**: Waveforms display synchronously right below your code editor pane.
- **Bi-Directional Cross-Probing**: Clicking any transition on a waveform trace immediately navigates your code cursor to the driving signal declaration or `always_ff` statement in your Verilog source.
- **Bus Expansion & Radix Formatting**: Expand multi-bit vectors into individual bits or change display representations to Hexadecimal, Binary, Signed Decimal, or ASCII with one keystroke.
- **Microsecond & Picosecond Precision Cursors**: Drop dual markers ($C_1$ and $C_2$) to measure clock cycle periods, setup times, and propagation delays ($\Delta T$).

## Cross-Probing Signals to Source RTL

One of SiliFlow's most beloved features is **Cross-Probing**:

```
[Waveform Pane]
clk    ───┐   ┌───┐   ┌───┐   ┌───┐   ┌───
rst_n  ───────┘   ────────────────────────
count  [00]───[01]───[02]───[03]───[04]───
                ▲
                │ Left-Click Transition at T=42.5ns
                ▼
[Source RTL Editor]
42:    always @(posedge clk or negedge rst_n) begin
43:        if (!rst_n) count <= 8'h00;
44:▶       else if (en) count <= count + 1'b1;  <-- Automatically highlighted!
45:    end
```

### How to use:
1. Hover over any value transition or glitch line on the waveform trace.
2. Hold `Ctrl` (or `Cmd` on macOS) and click the transition edge.
3. The editor immediately focuses the corresponding RTL file and highlights the line where that assignment occurred.

## Handling Large Traces (FST / Fast Trace Format)

While standard `.vcd` files are supported, large industrial runs generating tens of millions of cycles can create massive files. SiliFlow automatically streams `.fst` (Fast Signal Trace) files with on-demand chunk decompression:

```verilog
// In your testbench for ultra-fast dumping
initial begin
    $dumpfile("sim_output.fst");
    $dumpvars(0, counter_tb);
end
```

SiliFlow's streaming reader indexes signal offsets in memory, keeping RAM consumption under **80MB** even for multi-gigabyte traces.
