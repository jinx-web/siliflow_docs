# Interactive Waveform Viewer

SiliFlow embeds a native waveform viewer directly in the bottom panel or editor tab strip—eliminating context-switching to external windows for day-to-day verification.

{/* SCREENSHOT_SLOT: docs-waveform-viewer.png — Embedded Waveform Viewer with signal tree, bus transitions, Cursor A/B delta, and radix selector */}

---

## 1. Supported Formats & Rust `wellen` Parser

- Powered by the native Rust **`wellen`** parser (`commands/waveform.rs`), supporting both **VCD** (`.vcd`) and **FST** (`.fst`) waveform traces up to **100 MB** (with automatic fallback line-parser recovery for malformed VCD headers).
- Hold `Alt` while clicking **Waveform** in the Action Island (`Alt+Click`) to open waveforms directly in the secondary split pane beside your RTL code.

---

## 2. Key Capabilities

- **1-Bit & Multi-Bit Bus Rendering**: Clear digital transitions for scalar nets and packed vectors, with red **`X`** unknown-state hazard highlighting and amber **`Z`** high-impedance highlighting.
- **Radix Switching (`HEX` / `BIN` / `DEC` / `OCT`)**: Switch global bus representation cleanly across Hexadecimal, Binary, Decimal, and Octal.
- **Dual Measurement Cursors (`Cursor A` & `Cursor B`)**:
  - Place and inspect independent primary/secondary time markers (`Cursor A`, `Cursor B`).
  - View exact timestamps, **`ΔT` delta**, and derived **frequency (`Hz` / `kHz` / `MHz` / `GHz`)**, alongside live hover cursor time tracking.
- **Collapsible Scope Tree & Signal Filter**: Resizable signal sidebar (`70–450px`, saved across sessions), expandable DUT hierarchy scopes, scope dropdown filter, and substring/regex signal filter.
- **Go to Signal Definition & GTKWave Handoff**: Jump straight from a waveform signal to its RTL declaration via `VerilogWorkspaceIndex`, copy signal names/paths/values, or open huge external runs directly in **GTKWave** from the Run menu (`Run → Open in External GTKWave`).

---

## 3. Navigation Controls

| Interaction | Action |
| :--- | :--- |
| **Mouse Wheel** | Smooth zoom centered around cursor timestamp |
| **Click + Drag on Canvas** | Pan timeline horizontally |
| **Zoom In / Out / Fit All** | Toolbar zoom buttons to inspect clock cycles or fit full trace |
| **Cursor A / B Placement** | Click timeline ruler to inspect edges and measure `ΔT` / frequency |
