# Welcome to SiliFlow Studio

**SiliFlow Studio** is a unified, next-generation electronic design automation (EDA) workbench engineered specifically for modern silicon designers, verification engineers, and hardware students.

Traditional EDA software forces hardware engineers into fragmented, 1990s-era tooling: multi-gigabyte heavy installers, brittle external FlexLM license daemons, disjointed text editors, and external waveform viewing utilities like GTKWave that break flow every time you need to trace an assertion failure.

SiliFlow unifies the entire RTL lifecycle into an ultra-fast, single executable.

---

## Key Highlights

- **⚡ Sub-Millisecond Iterations**: Hit `F5` to trigger real-time compilation, testbench execution, and waveform rendering in under **40 milliseconds**.
- **📦 Single 45MB Binary**: Zero external daemon services, zero Java runtimes, zero complex license servers. Download, unpack, and launch.
- **📈 Integrated Waveform Canvas**: High-DPI hardware-accelerated waveform viewer built directly beneath the code editor. No alt-tabbing or external trace files needed.
- **🔍 Bi-Directional Cross-Probing**: Click any signal transition or assertion glitch in the waveform to jump directly to the exact driving line of Verilog/SystemVerilog RTL.
- **🔌 Multi-Engine Simulation Pipeline**: Out-of-the-box support for Icarus Verilog (`iverilog`), Verilator cycle-accurate C++ simulation, and native SiliFlow engine.
