# Welcome to SiliFlow Studio (`v1.2.0`)

**SiliFlow Studio** is a unified, offline-first electronic design automation (EDA) desktop workbench built for digital hardware engineers, ASIC/FPGA designers, and VLSI students.

Traditional EDA suites force hardware developers across disjointed GUIs, multi-gigabyte installers, brittle FLEXlm license servers, and external waveform popups. SiliFlow brings **RTL editing, split-pane navigation, multi-engine linting, Cocotb/`pyuvm` & coverage-driven simulation, streaming `2+ GB` `.vcd`/`.fst` waveforms, PDK-mapped Yosys schematics, FSM visualization, Static Timing Analysis (OpenSTA bridge + multi-corner PVT), CDC/RDC signoff, Formal LEC, native Rust physical design (2D & 3D), visual register map codegen, Git history, and an integrated multi-shell terminal** together inside one native window.

## Key Highlights (`v1.2.0`)

- **Native Tauri v2 + Rust Core**: Lightweight installer (**under 10 MB**), fast native cold start (**< 0.5s**), low idle footprint (**~65–85 MB**), non-blocking Tokio execution threads, configurable compile/simulation watchdog timer, and instant abort (<kbd>Shift+F5</kbd>).
- **100% Local-First IP Privacy**: Every compile, lint pass, `.vcd`/`.fst` parse, netlist elaboration, STA run, physical placement/routing pass, Formal LEC check, Git operation, and register map generation executes directly on your machine—zero cloud uploads.
- **Monaco Split-Pane HDL Studio**: Dual-pane split editor (<kbd>Ctrl+\\</kbd>), cross-file <kbd>F12</kbd> Go-to-Definition, `350ms` merged diagnostics across **Icarus Verilog**, **Verilator**, and **Slang**, **inline Waveform Cursor A signal overlays**, **coverage gutter highlights**, **STA critical-path overlays**, and **Command Palette**.
- **Simulation, Cocotb/`pyuvm`, Coverage & Mutation Testing**: Run behavioral **Icarus Verilog**, cycle-accurate **Verilator**, or **Cocotb / `pyuvm`** Python testbenches (`sequencer`/`driver`/`monitor`/`scoreboard`); inspect **Line/Branch/Toggle/SVA coverage**, **Random-Seed Sweeps**, **Worst-Case Seed Finder**, **RTL Fault-Injection Mutation Testing**, and **Protocol (`valid/ready`, `req/ack`) & Gate-Level Equivalence checks**.
- **Streaming `wellen` Waveform Viewer (`500 MB – 2+ GB`)**: Hierarchy-only open with Rust zoom-level LOD decimation and virtualized canvas; **Analog Step Plot**, per-signal formats (`Hex`, `UDec`, `SDec`, `Bin`, `ASCII`, `Analog`), **Dual Cursors (A & B)** + **Reference Clock Cycle Counter**, **Value/Edge Search**, **Named Markers (`M`)**, persistent watchlist, and **Pop-Out OS Window**.
- **PDK-Mapped Schematics, FSM & Pop-Out Windows**: Interactive **Yosys + `netlistsvg` Gate Schematic** supporting **SkyWater 130nm**, **GF180nm**, **IHP SG13G2 130nm**, **NanGate 45nm**, and custom `.lib`; `Ctrl+F` cell/net search, click-to-lock net tracing, submodule drill-down, SVG/PNG/Netlist JSON export, automatic **FSM Visualizer**, and dedicated **Pop-Out OS Windows**.
- **STA, CDC/RDC, Formal LEC & Native Rust Physical Flow**: **OpenSTA** bridge with multi-corner PVT & SDC constraints, **5-rule CDC/RDC**, **Yosys SAT Formal LEC**, and native Rust **Floorplan → SimPL Placement → Abacus Legalization → MMM/DME CTS → 3D PathFinder A\* Global Routing → DRC → DEF 5.8** with **2D & Three.js 3D Layout Viewers**.
- **Signed Auto-Updater**: Automatic Ed25519/minisign-verified desktop updates via `siliflow.in/update.json`.
