# Installation & Toolchains

SiliFlow Desktop Studio (`v1.2.0`) is distributed as a lightweight native **Tauri v2** application. Thanks to its compiled Rust backend and OS WebView frontend, the installer is **under 10 MB** and launches directly without JVM runtimes or license daemons.

---

## 1. Downloading SiliFlow Studio (`v1.2.0`)

Official installers are published on the public SiliFlow releases portal:

- **Latest Releases:** [https://github.com/jinx-web/siliflow-releases/releases/latest](https://github.com/jinx-web/siliflow-releases/releases/latest)
- **Website Quickstart:** <a href="/quickstart">siliflow.in/quickstart</a>

### Operating System Packages

| Operating System | Architecture | Package Format | Recommended Package | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **Windows** | x64 (64-bit) | `.exe` / `.msi` | `Siliflow_1.2.0_x64-setup.exe` / `.msi` | Windows 10 & 11 |
| **macOS** | Apple Silicon (M1–M4) | `.dmg` | `Siliflow_1.2.0_aarch64.dmg` | macOS 12 Monterey or newer |
| **Linux** | x86_64 (64-bit) | `.AppImage` / `.deb` | `Siliflow_1.2.0_amd64.AppImage` / `.deb` | Ubuntu, Debian, Fedora, Arch |

## 2. OS Installation Steps

### Windows
1. Download `Siliflow_1.2.0_x64-setup.exe` or `Siliflow_1.2.0_x64_en-US.msi`.
2. Run the setup wizard to create Desktop and Start Menu shortcuts.
3. Launch **SiliFlow**. On first launch, Windows can download SiliFlow's isolated managed toolchain with **SHA-256 verification** directly into `%LOCALAPPDATA%\Siliflow\tools`.

### macOS
1. Download `Siliflow_1.2.0_aarch64.dmg`.
2. Open the disk image and drag **Siliflow** into **Applications**.
3. On first launch, if macOS Gatekeeper warns about an unsigned beta build, right-click `Siliflow.app` in Finder and click **Open**.

### Linux

```bash
# Option A: Universal AppImage
chmod +x Siliflow_1.2.0_amd64.AppImage
./Siliflow_1.2.0_amd64.AppImage

# Option B: Debian / Ubuntu (.deb)
sudo dpkg -i Siliflow_1.2.0_amd64.deb
sudo apt-get install -f
```

## 3. Managed & Detected EDA Toolchains (`8` Binaries)

The Rust Toolchain Scanner checks SiliFlow's isolated managed folder first (`%LOCALAPPDATA%\Siliflow\tools` on Windows, `~/.siliflow/tools` on macOS/Linux) before falling back to MSYS2, OSS CAD Suite, and your system `PATH`.

| Binary | Role in SiliFlow Studio | Status |
| :--- | :--- | :--- |
| **Icarus Verilog** (`iverilog` + `vvp`) | Event-driven Verilog simulation & fast lint diagnostics | Core Simulation |
| **Verilator** (`verilator` / `verilator_bin`) | High-speed C++ / SystemVerilog compilation & lint verification | Core Simulation |
| **Yosys** (`yosys`) | Synthesis elaboration for Schematics, STA timing & CDC/RDC analysis | Synthesis & Signoff |
| **sv2v** (`sv2v`) | Automatic SystemVerilog-to-Verilog-2005 transpilation fallback | SV Compatibility |
| **Slang** (`slang`) | Deep IEEE 1800 SystemVerilog parser & real-time lint squiggles | SV Diagnostics |
| **Verible** (`verible-verilog-*`) | Style linting & formatting checks | Code Quality |
| **GTKWave** (`gtkwave`) | Optional external standalone waveform viewer launcher | Optional Handoff |

## 4. Platform Toolchain Setup Commands

### Windows (MSYS2 UCRT64 or One-Click Managed Install)

Inside SiliFlow, open **Tools → EDA Toolchain Manager** to run the **SHA-256-verified managed Windows installer** automatically, or install the full open-source suite via MSYS2 UCRT64:

```bash
pacman -S mingw-w64-ucrt-x86_64-iverilog \
          mingw-w64-ucrt-x86_64-verilator \
          mingw-w64-ucrt-x86_64-yosys
```

SiliFlow automatically searches `C:\msys64\ucrt64\bin`, `C:\msys64\mingw64\bin`, `C:\iverilog\bin`, and `C:\oss-cad-suite\bin` even if they are missing from your global Windows `PATH`.

### macOS (Homebrew)

```bash
brew install icarus-verilog verilator yosys sv2v slang
```

### Linux (Ubuntu / Debian)

```bash
sudo apt update
sudo apt install -y iverilog verilator yosys gtkwave
```

## 5. In-App Toolchain Verification & Environment Info

1. Check the bottom-right **Status Bar** indicator (`All Tools Ready` vs. `Tools Missing`).
2. Click it anytime (or open **Tools → EDA Toolchain Manager**) to inspect binary paths, run **Auto-Detect / Reload Toolchain**, or trigger a one-click managed download.
3. Click **Help → Copy Environment Info** to copy your OS, active simulator engine, and all detected binary paths directly to clipboard when filing bug reports.
