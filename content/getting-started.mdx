# Getting Started & Instant F5 Simulation

Get up and running with SiliFlow Studio in under two minutes. This guide walks you through workspace setup, writing your first synchronous RTL module, creating a testbench, and executing an instant simulation with `F5`.

---

## 1. Quick Installation

Download the official standalone archive for your operating system:

### Windows (MSI or Portable ZIP)
```powershell
# Extract portable distribution
Expand-Archive -Path siliflow-studio-win64.zip -DestinationPath C:\Tools\SiliFlow
# Launch SiliFlow IDE
C:\Tools\SiliFlow\siliflow.exe
```

### macOS (Homebrew or DMG)
```bash
brew install siliflow/tap/siliflow-studio
siliflow
```

### Linux (Tarball or AppImage)
```bash
chmod +x SiliFlow-x86_64.AppImage
./SiliFlow-x86_64.AppImage
```

## 2. Directory Structure Convention

SiliFlow automatically indexes standard hardware workspace conventions:

```text
my-silicon-project/
├── siliflow.config.json    # Project & simulation configuration
├── rtl/
│   └── counter.v           # Synthesizable RTL modules
└── tb/
    └── counter_tb.v        # Verification testbenches
```

---

## 3. Writing Your First RTL Module

Create a file named `rtl/counter.v`:

```verilog
`timescale 1ns / 1ps

module counter (
    input  wire       clk,
    input  wire       rst_n,
    input  wire       en,
    output reg  [7:0] count
);

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            count <= 8'h00;
        end else if (en) begin
            count <= count + 1'b1;
        end
    end

endmodule
```

## 4. Writing the Testbench

Create a testbench at `tb/counter_tb.v` with standard VCD trace dumps:

```verilog
`timescale 1ns / 1ps

module counter_tb;
    reg clk;
    reg rst_n;
    reg en;
    wire [7:0] count;

    // Instantiate Unit Under Test (UUT)
    counter uut (
        .clk(clk),
        .rst_n(rst_n),
        .en(en),
        .count(count)
    );

    // 100MHz Clock Generation
    always #5 clk = ~clk;

    initial begin
        // Configure VCD dump for SiliFlow viewer
        $dumpfile("sim_output.vcd");
        $dumpvars(0, counter_tb);

        clk   = 0;
        rst_n = 0;
        en    = 0;

        #20 rst_n = 1;
        #10 en    = 1;
        #100 en   = 0;
        #30  en   = 1;
        #50  $finish;
    end
endmodule
```

---

## 5. The Magic: Instant F5 Simulation

With both files open in SiliFlow:

1. Press **`F5`** (or click the blue **▶ Simulate** button in the header toolbar).
2. SiliFlow automatically invokes the target simulator (default: `iverilog` or native engine).
3. Within **~38ms**, the embedded waveform pane pops up directly underneath your editor displaying active clock transitions and signal buses.

> **Tip:** You can press **`Ctrl + R`** (or **`Cmd + R`** on macOS) to hot-reload simulation traces without restarting the IDE or re-scrolling your waveform view.
