# Getting Started & Workspaces

Siliflow is designed to feel familiar to anyone who has used VS Code, but purpose-built with silicon engineering workflows at its core.

---

## 1. Opening a Workspace

When you launch Siliflow, you are welcomed by the onboarding screen:

- **Open Folder**: Select any local directory containing Verilog (`.v`), SystemVerilog (`.sv`, `.svh`), or header (`.vh`) files.
- **Try Demo Project**: One-click onboarding button on the Welcome screen or Explorer sidebar. It instantly loads the included `demo_project` containing a 4-bit synchronous counter, full testbench, and preconfigured simulation scripts.
- **Clone from URL**: Clone any Git hardware repository (e.g., from GitHub or GitLab) directly into your workspace.
- **Recent Workspaces**: Instantly re-open your most recent projects from the quick-access list.

## 2. Workspace Project Structure (`project.json`)

Siliflow works seamlessly with raw Verilog files, but you can also define a `project.json` in your workspace root for advanced build automation:

```json
{
  "name": "counter_project",
  "topModule": "counter_tb",
  "sourceFiles": [
    "src/counter.v",
    "sim/counter_tb.v"
  ],
  "includeDirs": [
    "include"
  ],
  "defines": [
    "DEBUG_MODE"
  ],
  "testbenches": [
    {
      "name": "counter_tb",
      "file": "sim/counter_tb.v",
      "simulator": "iverilog"
    },
    {
      "name": "fast_counter_tb",
      "file": "sim/counter_tb.v",
      "simulator": "verilator"
    }
  ]
}
```

### Configuration Fields

| Field | Type | Description |
| :--- | :--- | :--- |
| `name` | `string` | Display name of the silicon project |
| `topModule` | `string` | Primary default root module |
| `sourceFiles` | `string[]` | Ordered list of source RTL and testbench files |
| `includeDirs` | `string[]` | Directory paths passed via `-I` to simulators |
| `defines` | `string[]` | Macro definitions passed via `-D` to compilers |
| `testbenches` | `array` | Dedicated list of testbench targets with engine presets |

## 3. UI Overview & Layout

Siliflow is divided into 5 focused functional zones:

1. **Title Bar**:
   - Quick file switcher & Command Palette (<kbd>Ctrl+P</kbd>).
   - Global **Save** (<kbd>Ctrl+S</kbd>).
   - Quick **Simulate** action button.
   - **Waveform** and **Schematic** toggle buttons.
2. **Activity Bar** (Far Left):
   - **Explorer**: File management, new file/folder, drag-and-drop.
   - **Search Across Files** (<kbd>Ctrl+Shift+F</kbd>): Regex, case-sensitive search.
   - **Module Hierarchy Tree**: Real-time instantiated RTL tree.
   - **Source Control**: Git branch, commit, stage, discard, and diff viewer.
3. **Editor Area**:
   - Multi-tab Monaco code editor.
   - Middle-click tab close support.
   - Split view and watermark empty state.
4. **Bottom Panel**:
   - **Problems**: Live syntax, parser, and lint diagnostics.
   - **Output**: Detailed compilation logs.
   - **Terminal**: Embedded interactive silicon terminal.
   - **Waveform**: Embedded interactive VCD waveform canvas.
   - **Run History**: Historical record of compilation times, passes, and fails.
   - **Regression**: Pass/fail table for automated test suite execution.
5. **Status Bar** (Bottom):
   - Active Git branch.
   - Problems counter.
   - Active terminal toggle.
   - EDA Toolchain status pill.
   - Cursor position (Line / Column), encoding, and active language mode.
