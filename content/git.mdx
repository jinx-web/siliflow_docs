# Git Source Control, Diffs & Commit Graph

SiliFlow integrates Git workflows right alongside your RTL workspace so you can branch, diff changes, inspect commit history, and sync repositories without leaving the studio.

{/* SCREENSHOT_SLOT: docs-git-graph.png — Git Commit Graph alongside Source Control diff viewer and Status Bar branch indicator */}

---

## 1. Source Control Sidebar (`Ctrl+Shift+G`)

Open the **Source Control** panel from the Activity Bar or press <kbd>Ctrl+Shift+G</kbd>:

- **Staged vs. Unstaged Tracking**: View live file badges (`M`, `A`, `D`, `?`) across both the File Explorer tree and Source Control sidebar.
- **Stage, Unstage & Discard**: Stage/unstage individual files or everything at once, or discard working-tree edits safely with confirmation.
- **Commit, Push, Pull & Init**: Write commit messages, run `git commit`, **Push** / **Pull** tracking ahead (`↑`) / behind (`↓`) counters in the bottom Status Bar, or initialize new repos (`git init`).
- **Clone Repository (<kbd>Ctrl+Shift+V</kbd>)**: Clone remote GitHub/GitLab hardware repositories directly from the Welcome screen, **File → Clone Repository...**, or Command Palette.

---

## 2. Built-In Diff Viewer & Visual Commit Graph

- **Diff Viewer**: Click any modified file in Source Control to inspect inline/side-by-side changes before committing.
- **Git Commit Graph (`View → Git Commit Graph`)**: Browse commit history visually with branch lines, commit metadata, changed file lists, and per-commit file diffs inside SiliFlow.
